Editor FAQ

Frequently Asked Questions on Editor & Execution

Quick answers to common questions about using the online compiler and IDE.

How do I execute Python or Web code in the editor?

Direct Answer: Click the green 'Run' button in the status bar or press the keyboard shortcut Ctrl+Enter (Cmd+Enter on macOS). Python output displays immediately in the bottom console panel.

What keyboard shortcuts are supported in the Monaco Editor?

Direct Answer: The editor supports standard VS Code shortcuts: Ctrl+Enter to run code, Ctrl+Z to undo, Ctrl+Y to redo, Ctrl+F to search, Ctrl+H to replace, Alt+Click for multi-cursor editing, and Ctrl+/ to toggle comments.

Which Python libraries are available in the in-browser runtime?

Direct Answer: All Python 3.12 standard libraries are supported (math, random, sys, json, re, datetime, itertools, collections, statistics) alongside popular WebAssembly packages.

How do I download or export my project?

Direct Answer: Click the 'Download' button in the top action toolbar to export your active script, or use the ZIP export option to download your full multi-file workspace.

Can I use the editor offline without an active internet connection?

Direct Answer: Yes. Once the editor assets and Pyodide WebAssembly runtime are cached in your browser during your initial visit, code compilation and editing work offline seamlessly.
